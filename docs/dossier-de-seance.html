49.MÈME
ADOPTÉ SANS VOTE

Avant toute chose

Ce qui peut tuer le projet

Le concept est bon et le timing aussi. Voici les angles morts, du plus grave au moins grave.

Critique · juridique

« Choquer » a une limite pénale

La caricature politique est protégée en France. Les deepfakes sexuels, les montages présentés comme réels, l'injure à caractère raciste ou antisémite et le harcèlement ne le sont pas, et pèsent sur toi en tant qu'hébergeur dès qu'un joueur uploade.

Le choc doit venir de l'absurde et de l'irrévérence, pas de la haine. La V1 a déjà un bouton « Signaler » qui retire l'image tout de suite. Il faut ajouter des mentions légales et une adresse de contact.

Critique · croissance

La viralité est dans le partage, pas dans le jeu

Une partie entre potes ne sort pas du groupe. Ce qui fait venir de nouveaux joueurs, c'est le top 3 posté sur TikTok, Insta ou WhatsApp, avec le logo et le code de la room.

L'export du top 3 en image partageable doit être la toute première priorité après la V1, pas une option « plus tard ».

Élevé · produit

Il faut 3 amis connectés en même temps

Tous les party games ont ce problème au démarrage. Un joueur seul qui arrive par un lien TikTok ne peut pas jouer.

Deux réponses : un mode streamer (le chat vote via un lien, c'est comme ça que Make It Meme a grandi) et un mode solo « mème du jour ».

Élevé · image

Taper sur un seul camp coupe l'audience en deux

Si la banque d'images vise surtout un bord, l'app sera étiquetée militante, perdra la moitié de son public et pourra être signalée en masse.

Équilibrer les 40 à 60 images entre tous les candidats. La colonne tags permet de vérifier l'équilibre en une requête.

Élevé · juridique

Les photos de presse ont un auteur

Le droit à l'image d'un politique est limité, mais une photo AFP ou Getty reste protégée par le droit d'auteur, parodie ou pas.

Privilégier Wikimedia Commons, les photos officielles sous licence ouverte et les captures de moments télévisés détournés. Les colonnes license et source_url servent à tracer l'origine.

Moyen · distribution

« App mobile » ne veut pas dire App Store

La validation Apple prend plusieurs jours et les règles sur le contenu politique visant des personnes réelles sont strictes. Incompatible avec un MVP en un jour.

Choix retenu : une web app installable (PWA). Un lien suffit pour rejoindre, ce qui est mieux pour la viralité. Le store pourra venir plus tard.

Moyen · coûts

Le plan gratuit de Supabase plafonne vite

200 connexions temps réel simultanées et 5 Go de bande passante par mois. Avec des GIF de 2 Mo, un pic viral les épuise en quelques heures.

Passer Supabase en Pro (25 $/mois) avant toute communication, et convertir les GIF en MP4 dans une version suivante.

Moyen · élection

Un classement de votes ressemble à un sondage

Publier « Le candidat le plus adopté sur 49.meme » à l'approche du scrutin peut être lu comme un sondage, ce qui est très encadré en période électorale.

Communiquer sur les mèmes, jamais sur des scores agrégés par candidat.

Bilan stratégique

Positionnement et boucle virale

Promesse : « Adopté sans vote. » Le 49.3 devient le ressort comique du jeu : ton mème passe en force. Les trois boutons de vote parlent à tout le monde, quel que soit son bord :

🔥 Macron démission · +2 😐 Valls revient · 0 🧨 49.3 · −1

Cible

Les 16-30 ans qui suivent la politique comme un feuilleton sur TikTok, X et Twitch. Ils ne votent pas forcément, mais ils commentent tout. Cible secondaire : les streamers politiques et humoristes qui jouent en live avec leur communauté.

La boucle

Moment politique→ Partie entre amis→ Top 3 exporté→ Story ou TikTok→ Nouveaux joueurs

Le carburant, c'est l'actualité : annonces de candidature, débats télévisés, petites phrases. Il faut pouvoir ajouter des images du soir même dans la banque, ce que permet déjà la V1 avec un simple dépôt dans le Storage suivi de select sync_library();.

Bilan technique

La plateforme V1

Pas de Node installé sur la machine et un délai d'un jour : l'interface est donc en HTML et JavaScript sans étape de build, servie directement par Vercel. Toute la logique de jeu vit dans Postgres, ce qui rend le serveur seul juge des règles.

Déroulé d'une partie

Lobbyhôte lance Légende 45 schrono ou tous validés Vote 9 s × Ndernier mème Résultatsround suivant ↺ ou Podium

Si l'hôte perd le réseau, n'importe quel joueur fait avancer la partie quand le chrono expire. Le serveur vérifie l'heure et verrouille la ligne, donc la partie ne se bloque jamais.

Mise en ligne · environ 15 minutes

Brancher en live

  1. Créer le projet Supabase en région Paris (eu-west-3).supabase.com → New project
  2. Exécuter le schéma : coller tout le fichier supabase/migrations/0001_init.sql et lancer.SQL Editor → New query → Run
  3. Activer la connexion anonyme.Authentication → Sign In / Providers → Allow anonymous sign-ins
  4. Déposer la banque d'images dans le dossier library du bucket memes. Nommer les fichiers macron-debat-01.gif : les mots deviennent des tags.Storage → memes → Create folder « library » → Upload
  5. Importer les images en base, puis relancer après chaque ajout : 
    select public.sync_library();
  6. Renseigner les clés (Project URL et clé anon) dans public/js/config.js. Cette clé est publique par conception, la sécurité est assurée côté base.Project Settings → API
  7. Pousser sur GitHub dans un repo privé, depuis le dossier du projet : 
    git init && git add . && git commit -m "V1 49.meme" && git branch -M main
git remote add origin https://github.com/VOTRE-COMPTE/49meme.git
git push -u origin main
  8. Importer le repo dans Vercel, framework « Other », puis Deploy. Chaque push sur main redéploie, chaque branche a son URL de test.vercel.com → Add New → Project

Le projet est dans OneDrive : la synchronisation peut abîmer le dossier .git. Mieux vaut cloner le repo dans un dossier hors OneDrive après le premier push. Pour tester sans backend, ouvrir l'app avec ?demo : 3 bots jouent avec toi.
